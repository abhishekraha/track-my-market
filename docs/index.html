Engineering Specifications

Zero-Allocation Architecture

Engineered with mechanical sympathy: lock-free ring buffers, direct off-heap memory, and non-blocking Java 25 virtual thread concurrency.

No Demat / No KYC Ingestion

Directly interfaces with public market feeds using automated session cookie (A3) and cryptographic crumb renewal. Eliminates expensive broker subscriptions, KYC audits, and static IP whitelisting.

YahooFinanceProvider Crumb Negotiation Deduplication

Zero-Allocation SBE v1

Simple Binary Encoding (SBE) compiles binary flyweights backed by Agrona UnsafeBuffer. Encodes prices as scaled uint64 (factor 10^4) and nanosecond epoch timestamps in a fixed 64-byte frame.

64-Byte Message Agrona DirectBuffer 0 Heap Garbage

Embedded Aeron Media Driver

Streams market data across processes via POSIX shared memory ring buffers (/dev/shm) using Real Logic Aeron. Achieves sub-microsecond IPC transit latency with zero thread contention.

aeron:ipc?stream-id=1001 < 1 μs Transit Archiving Driver

Optional SSE Trading Desk

Embedded HTTP server powered by Java 25 virtual threads multicasting Server-Sent Events (SSE). Seamlessly feeds TradingView Lightweight Charts v4 with sub-millisecond browser dispatch.

Virtual Threads Lightweight Charts v4 Dynamic Watchlist

Containerized with 512MB dedicated shared memory allocation (shm_size: 512m) and an Nginx reverse proxy configured with proxy_buffering off for zero-latency SSE delivery.

# 2. Launch containerized Aeron engine & Nginx reverse proxy
