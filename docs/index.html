High-Frequency Engineering

Zero-Allocation Architecture

Engineered with mechanical sympathy: lock-free ring buffers, direct off-heap memory, and non-blocking Java 25 virtual thread concurrency.

Embedded Aeron IPC

Communication runs over POSIX shared-memory mapped files without OS kernel context switches. Sub-microsecond ring buffer transit latency even under heavy multi-ticker throughput.

SBE v1 Zero-Copy Codec

Simple Binary Encoding formats quotes directly into off-heap direct byte buffers (UnsafeBuffer). Eliminates heap garbage collector allocation pauses completely in the critical broadcast path.

Java 25 Virtual Threads

Lightweight Thread.ofVirtual() orchestration handles 10,000+ persistent Server-Sent Event (SSE) client streams without thread pool exhaustion or blocking kernel OS threads.

Two-Tier Nginx Ingress

Internal Nginx reverse proxy fronts the Java engine. Delivers asset gzip compression, buffers-free SSE streaming (proxy_buffering off;), and shields the internal Aeron media driver threads.

Deployment Guide

Get Started in 60 Seconds

Launch the complete containerized stack with one command or run the native Java 25 binary.

# 1. Clone repository
git clone https://github.com/abhishekraha/track-my-market.git
cd track-my-market

# 2. Launch containerized Aeron engine & Nginx reverse proxy
docker compose up -d

# 3. Access the trading desk in your browser:
# http://localhost:8081/ (Nginx reverse proxy with gzip on port 8081)
# http://localhost:8080/ (Raw Java Virtual Thread engine on port 8080)
# 1. Ensure JAVA_HOME points to Java 25:
$env:JAVA_HOME = "$HOME\.jdks\jdk-25.0.4-lite"

# 2. Compile SBE stubs and launch trading desk
./gradlew run --args="--enable-ui"

# 3. Open http://localhost:8080/ in browser
# Launch low-footprint console terminal consumer
./gradlew run

# Or stream live logs from the running Docker container:
docker compose logs -f track-my-market
